# Company_Sales_analysis: Excel

Hi, I'm Lonwabo

This repository is a self-directed portfolio project using company sales data to analyse monthly and yearly revenue, and profits by country.

**Dataset note**: This dataset is taken from kaggle and not a real world data from any company.

**Business questions**
1. Can you summarize the revenue, profit, and cost columns?

   •Descriptive statistics is used to answer this question.

2. What is the total sales revenue?
3. How does revenue change from Month to Month?
4. Which regions contribute the most revenue?
   
   • These 3 questions answered using a Pivot table.
   
**Portfolio summary**

This is an end-to-end portfolio using Excel. The data is cleaned, removed duplicates, invalid values, and changed the format. Calculated profit margin and created an interactive dashboard to compare sales.
